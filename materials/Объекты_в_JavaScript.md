# Объекты в JavaScript

Объект — один из основных способов объединить связанные данные в JavaScript. Если массив хранит значения по числовым индексам, то объект хранит данные в виде пар **ключ — значение**.

На этом занятии важно научиться создавать объекты, читать и изменять их свойства, перебирать свойства, использовать встроенные методы `Object` и писать простые методы объекта с `this`.

## 1. Зачем нужны объекты

Без объекта данные об одном человеке могут храниться в отдельных переменных:

```js
const name = "Иван";
const age = 19;
const group = "ПВ-221";
```

Такая запись становится неудобной, когда данных много. Связанные значения можно объединить:

```js
const student = {
  name: "Иван",
  age: 19,
  group: "ПВ-221"
};
```

Теперь одна переменная `student` описывает одну сущность.

## 2. Создание объекта

Чаще всего объект создают с помощью литерала `{}`:

```js
const user = {
  name: "Alex",
  age: 20,
  isAdmin: false
};
```

Ключи объекта также называют **свойствами**.

Значениями могут быть числа, строки, логические значения, массивы, другие объекты и функции:

```js
const student = {
  name: "Иван",
  age: 19,
  grades: [5, 4, 5],
  address: {
    city: "Алматы",
    street: "Абая"
  }
};
```

## 3. Точечная и скобочная запись

Если имя свойства известно заранее, обычно используется точка:

```js
console.log(user.name);
console.log(user.age);
```

Другой вариант — квадратные скобки:

```js
console.log(user["name"]);
console.log(user["age"]);
```

Скобочная запись особенно важна, когда имя свойства находится в переменной:

```js
const key = "name";

console.log(user[key]);
```

Запись `user.key` в этом случае искала бы свойство с буквальным именем `key`.

## 4. Добавление и изменение свойств

Объект можно изменять после создания:

```js
const user = {
  name: "Alex",
  age: 20
};

user.age = 21;
user.city = "Алматы";

console.log(user);
```

Объявление через `const` запрещает присвоить переменной новый объект, но не запрещает менять свойства существующего объекта:

```js
const user = { name: "Alex" };

user.name = "Ivan";       // можно
user.age = 19;            // можно

// user = { name: "Max" } // нельзя
```

## 5. Удаление свойства

Для удаления используется оператор `delete`:

```js
const user = {
  name: "Alex",
  age: 20,
  city: "Алматы"
};

delete user.city;

console.log(user);
```

В обычных задачах удаление требуется нечасто, но синтаксис полезно знать.

## 6. Проверка существования свойства

Оператор `in` проверяет наличие свойства:

```js
const user = {
  name: "Alex",
  age: 20
};

console.log("name" in user); // true
console.log("city" in user); // false
```

Также можно использовать:

```js
console.log(Object.hasOwn(user, "name")); // true
```

Для учебных задач этого достаточно; различия между собственными и унаследованными свойствами подробно понадобятся позже при изучении прототипов и ООП.

## 7. Перебор через `for...in`

На прошлом занятии `for...in` упоминался как цикл, который перебирает ключи. Для объектов это его естественное применение:

```js
const user = {
  name: "Alex",
  age: 20,
  city: "Алматы"
};

for (const key in user) {
  console.log(key, user[key]);
}
```

Здесь:

- `key` — имя текущего свойства;
- `user[key]` — значение этого свойства.

Обратите внимание: внутри цикла используется именно скобочная запись.

## 8. `Object.keys()`, `Object.values()`, `Object.entries()`

### `Object.keys()`

Возвращает массив ключей объекта:

```js
const user = {
  name: "Alex",
  age: 20
};

console.log(Object.keys(user));
// ["name", "age"]
```

Поэтому количество свойств можно получить так:

```js
console.log(Object.keys(user).length);
```

### `Object.values()`

Возвращает массив значений:

```js
console.log(Object.values(user));
// ["Alex", 20]
```

Полученный массив можно перебирать уже знакомым `for...of`:

```js
for (const value of Object.values(user)) {
  console.log(value);
}
```

### `Object.entries()`

Возвращает массив пар `[ключ, значение]`:

```js
console.log(Object.entries(user));
// [["name", "Alex"], ["age", 20]]
```

Один из удобных вариантов перебора:

```js
for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}
```

Запись `[key, value]` называется деструктуризацией массива. Пока достаточно понимать её как удобный способ сразу получить два элемента пары.

## 9. Вычисляемое имя свойства

Если ключ заранее хранится в переменной, его можно использовать при создании объекта:

```js
const fieldName = "score";

const result = {
  [fieldName]: 95
};

console.log(result.score); // 95
```

Без квадратных скобок было бы создано свойство с именем `fieldName`.

## 10. Сокращённая запись свойств

Если имя переменной совпадает с именем свойства, JavaScript позволяет записать короче:

```js
const name = "Иван";
const age = 19;

const student = {
  name,
  age
};

console.log(student);
```

Это то же самое, что:

```js
const student = {
  name: name,
  age: age
};
```

## 11. Методы объекта

Значением свойства может быть функция. Такую функцию называют **методом объекта**:

```js
const user = {
  name: "Alex",

  sayHello() {
    return "Привет!";
  }
};

console.log(user.sayHello());
```

Метод вызывается так же, как обычная функция, но через объект.

## 12. `this` внутри метода

Часто метод должен использовать данные того же объекта:

```js
const user = {
  name: "Alex",
  age: 20,

  introduce() {
    return `Меня зовут ${this.name}, мне ${this.age} лет`;
  }
};

console.log(user.introduce());
```

В таком простом вызове `user.introduce()` значение `this` внутри метода указывает на объект `user`.

Для этого занятия достаточно правила:

> В обычном методе объекта `this` позволяет обратиться к свойствам объекта, для которого вызывается этот метод.

Тема `this` намного шире. `call()`, `apply()`, `bind()` и сложные случаи будут нужны позже.

### Почему метод с `this` пока лучше писать обычным синтаксисом

Не стоит заменять такой метод стрелочной функцией:

```js
const user = {
  name: "Alex",

  // Неудачный вариант для метода, которому нужен this
  sayName: () => {
    return this.name;
  }
};
```

У стрелочной функции нет собственного `this`, поэтому она ведёт себя иначе. До подробного разбора `this` методы объекта удобнее писать так:

```js
sayName() {
  return this.name;
}
```

## 13. Вложенные объекты и массивы

Объекты часто содержат другие структуры:

```js
const student = {
  name: "Иван",
  grades: [5, 4, 5],
  address: {
    city: "Алматы",
    street: "Абая"
  }
};

console.log(student.grades[1]);       // 4
console.log(student.address.city);    // Алматы
```

Это обычная комбинация уже знакомых конструкций.

## 14. Массив объектов

Один из самых частых вариантов представления данных:

```js
const products = [
  { name: "Mouse", price: 5000 },
  { name: "Keyboard", price: 12000 },
  { name: "Monitor", price: 85000 }
];
```

Массив можно перебрать:

```js
for (const product of products) {
  console.log(product.name, product.price);
}
```

Или использовать уже изученные методы массивов:

```js
const expensive = products.filter((product) => product.price >= 10000);
console.log(expensive);
```

Именно массивы объектов позже будут часто встречаться при работе с JSON, DOM и данными, полученными от сервера.

## 15. Копирование объекта: поверхностная копия

Для простого объекта можно создать копию через spread:

```js
const user = {
  name: "Alex",
  age: 20
};

const copy = { ...user };

copy.age = 21;

console.log(user.age); // 20
console.log(copy.age); // 21
```

Можно также объединять объекты:

```js
const base = {
  name: "Alex",
  age: 20
};

const additional = {
  city: "Алматы",
  age: 21
};

const result = {
  ...base,
  ...additional
};

console.log(result);
```

Если ключ повторяется, значение справа перезаписывает предыдущее.

Важно: такая копия является **поверхностной**. Подробно вложенные ссылки разберём позже, когда это будет действительно нужно.

## 16. Небольшой пример: объект товара

```js
const product = {
  name: "Keyboard",
  price: 12000,
  quantity: 2,

  getTotal() {
    return this.price * this.quantity;
  }
};

console.log(product.getTotal()); // 24000

product.quantity = 3;

console.log(product.getTotal()); // 36000
```

Здесь метод не хранит заранее вычисленную сумму, а использует текущие значения объекта.

## 17. Что важно запомнить

- объект хранит данные в виде `ключ: значение`;
- `obj.key` удобен, когда имя свойства известно заранее;
- `obj[key]` нужен для динамического имени свойства;
- объект, объявленный через `const`, можно изменять изнутри;
- `for...in` перебирает ключи объекта;
- `Object.keys()` возвращает ключи;
- `Object.values()` возвращает значения;
- `Object.entries()` возвращает пары `[ключ, значение]`;
- функция внутри объекта называется методом;
- в обычном методе `this` позволяет обратиться к текущему объекту;
- массив объектов — одна из основных форм представления наборов данных в JavaScript.

На следующем этапе объекты станут основой для знакомства с классами и ООП.
