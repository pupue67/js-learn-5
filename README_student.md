# Практическая работа №5

## Тема

Объекты в JavaScript.

## Запуск тестов

```bash
node tests.js
```

## Что нужно заполнить

Откройте `student-template.js` и заполните участки `TODO`.

Не изменяйте:

- названия функций;
- список параметров функций;
- блок `module.exports` в конце файла.

В работе используются уже изученные функции, циклы, массивы и новые конструкции для объектов: точечная и скобочная запись, `for...in`, `Object.keys()` и методы объекта с `this`.

Полные условия, ограничения и примеры находятся в документе `Практическая_работа_5.docx`.

## Сдача

Для этой работы отдельная загрузка в учебную систему не требуется. Работа размещается и выполняется в вашем GitHub-репозитории в привычном формате.

В репозитории должны находиться:

- заполненный `student-template.js`;
- при необходимости краткий README с инструкцией запуска;
- при выполнении дополнительного браузерного задания — JS-файл с вводом через `prompt()` и выводом через `alert()` или `console.log()`.

Перед завершением обязательно выполните:

```bash
node tests.js
```

Все группы тестов должны завершиться успешно.
